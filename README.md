# Treinando uma IA de Aprendizagem com NotebookLM

## Objetivo do Projeto

Este projeto tem como objetivo explorar o uso do NotebookLM como ferramenta de aprendizagem ativa aplicada a CRM, Inteligência Artificial e eficiência comercial.

A proposta é utilizar IA para:
- organizar conhecimento;
- gerar resumos;
- criar revisões inteligentes;
- estruturar prompts reutilizáveis;
- melhorar a análise de informações.

---

# Tema Escolhido

IA aplicada a CRM e Eficiência Comercial no Setor Bancário.

---

# Objetivos de Estudo

- Entender como IA pode apoiar estratégias de CRM;
- Aprender conceitos de Product Mindset;
- Explorar engenharia de prompts;
- Melhorar capacidade analítica;
- Estruturar um sistema inteligente de estudos.

---

# Ferramentas Utilizadas

- NotebookLM
- GitHub
- Inteligência Artificial Generativa
- Salesforce (conceitos de CRM)
- Engenharia de Prompts
